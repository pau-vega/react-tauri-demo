## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> TodoInput -> useTodos | User-typed text flows into React state, then to store |
| TodoList rendering -> DOM | Stored data rendered into HTML elements |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Injection | TodoInput -> todo.text -> DOM | mitigate | React's JSX auto-escapes text content in `<span>{todo.text}</span>`. No `dangerouslySetInnerHTML` used. XSS via stored text is prevented by React's default escaping. |
| T-02-07 | Tampering | TodoItem onToggle/onDelete callbacks | accept | Callbacks are passed from parent via props. No user-controllable callback injection vector in this architecture. Local-only app. |
| T-02-08 | Repudiation | Todo operations (add/toggle/delete) | accept | No audit log needed. Single-user local app. User performs all actions themselves. |
</threat_model>
