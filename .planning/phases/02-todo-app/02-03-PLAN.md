Present the following verification steps to the user. This is a checkpoint -- Claude has already built and launched the app in Task 1. The user now verifies the 5 ROADMAP Phase 2 success criteria on the running Android app.

**What was built:** Complete todo app with add/toggle/delete operations and persistent storage via Tauri Store plugin. The app replaces the Phase 1 verification screen with a functional todo list.

**How to verify -- with the app running on Android (via `pnpm tauri android dev`):**

1. Add a todo (TODO-01):
   - The input field should be auto-focused with placeholder "Add a todo..."
   - Type "Buy groceries" and tap the "Add" button
   - The todo should appear in the list below
   - The input should clear and re-focus
   - Try pressing Enter to add another todo "Walk the dog"

2. Toggle complete/incomplete (TODO-02):
   - Tap the circle on the left of "Buy groceries"
   - It should fill with blue and show a checkmark
   - The text should get strikethrough styling and become dimmed (gray)
   - Tap it again -- it should revert to incomplete (outline circle, normal text)

3. Delete a todo (TODO-03):
   - Tap the X button on the right of "Walk the dog"
   - The todo should disappear immediately from the list

4. Empty state (TODO-04):
   - Delete all remaining todos
   - You should see "No todos yet" with "Add your first todo above" below it

5. Persistence across restart (PERS-02):
   - Add 2-3 todos, complete one of them
   - Force-close the app completely (swipe away from recent apps)
   - Reopen the app
   - All todos should be present with their completion states preserved

**Resume signal:** Type "approved" if all 5 criteria pass, or describe which criterion fails and what you observe.
