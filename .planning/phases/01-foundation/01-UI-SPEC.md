# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | none | CONTEXT.md D-21, REQUIREMENTS.md Out of Scope: @monorepo-template/ui |
| Preset | not applicable | Phase 1 is standalone experiment |
| Component library | none | REQUIREMENTS.md explicitly excludes @monorepo-template/ui |
| Icon library | none | No icons needed in verification screen |
| Font | system-ui, -apple-system, sans-serif | CONTEXT.md D-21: system fonts only |

Phase 1 produces a single standalone verification screen inside `apps/tauri-todo`. It does NOT use the monorepo `packages/ui` library, shadcn, or any shared component registry. Tailwind CSS 4 is used directly via `@tailwindcss/vite`.

---

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Label-to-input gaps |
| sm | 8px | Inline element spacing, button padding vertical |
| md | 16px | Default element spacing, input padding |
| lg | 24px | Section padding, card padding |
| xl | 32px | Layout gaps between sections |
| 2xl | 48px | Page vertical padding |
| 3xl | 64px | Not used in Phase 1 |

Exceptions: none. Phase 1 UI is intentionally minimal — most layouts use md (16px) and lg (24px).

---

## Typography

System font stack only. No web font imports. Source: CONTEXT.md D-21.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Input labels, response text, version info |
| Label | 14px | 500 | 1.4 | Section labels, field captions |
| Heading | 20px | 600 | 1.2 | Verification screen title ("Tauri Todo — Verification") |
| Display | 28px | 700 | 1.1 | Not used in Phase 1 |

Tailwind classes:
- Body: `text-base font-normal leading-normal`
- Label: `text-sm font-medium`
- Heading: `text-xl font-semibold`

## Color

Light-only color scheme. Source: CONTEXT.md D-27. No dark mode in Phase 1.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (white) | Page background |
| Secondary (30%) | `#f3f4f6` (gray-100) | Section card backgrounds, info panels |
| Accent (10%) | `#1d4ed8` (blue-700) | Primary action button background only |
| Destructive | not applicable | No destructive actions in Phase 1 |
| Text primary | `#111827` (gray-900) | All body and heading text |
| Text secondary | `#6b7280` (gray-500) | Version info, captions |
| Border | `#e5e7eb` (gray-200) | Input borders, card outlines |
| Success indicator | `#16a34a` (green-600) | Store read/write success message text only |
| Error indicator | `#dc2626` (red-600) | IPC error message text only |

Accent reserved for: the "Send Greeting" button background and the "Test Store" button background. No other elements use blue-700.

Tailwind classes reference (Tailwind 4 with inline theme):
- Background: `bg-white`
- Secondary surface: `bg-gray-100`
- Primary button: `bg-blue-700 text-white`
- Primary text: `text-gray-900`
- Muted text: `text-gray-500`
- Border: `border-gray-200`

## Layout — Verification Screen

The entire Phase 1 UI is one screen: a verification checklist that proves the full stack works.

### Screen Structure (top to bottom)

```
┌──────────────────────────────────────┐
│  [Page padding: 48px top]            │
│  Tauri Todo — Verification           │  ← Heading (text-xl, semibold)
│                                      │
│  ┌──── IPC Section ──────────────┐   │
│  │  Name: [____________] [Send]  │   │
│  │  Response: Hello, {name}!     │   │
│  └───────────────────────────────┘   │
│                                      │
│  ┌──── Store Section ─────────────┐  │
│  │  [Test Store]                  │  │
│  │  Status: Write OK / Read OK    │  │
│  └────────────────────────────────┘  │
│                                      │
│  ┌──── Version Info ──────────────┐  │
│  │  Tauri: 2.x.x                  │  │
│  │  React: 19.x.x                 │  │
│  │  Platform: android / web       │  │
│  └────────────────────────────────┘  │
│                                      │
│  [Page padding: 48px bottom]         │
└──────────────────────────────────────┘
```

- Max content width: 480px, horizontally centered
- Page background: white
- Each section: gray-100 card, 24px padding, 8px border-radius, gray-200 border

### Tailwind Layout Classes

```
<main class="min-h-screen bg-white px-4 py-12 flex flex-col items-center">
  <div class="w-full max-w-md flex flex-col gap-6">
    <h1 class="text-xl font-semibold text-gray-900">Tauri Todo — Verification</h1>
    <!-- sections -->
  </div>
</main>
```

Section card:
```
<section class="bg-gray-100 border border-gray-200 rounded-lg p-6 flex flex-col gap-4">
```

## Interactive Elements

### Name Input (IPC section)

- Height: 40px minimum
- Full width within section
- Padding: 8px horizontal (inside the field)
- Border: 1px gray-200
- Background: white
- Border-radius: 6px
- Placeholder text: "Enter your name"
- On focus: blue-700 ring (2px)

Tailwind: `w-full h-10 px-3 bg-white border border-gray-200 rounded-md text-base text-gray-900 focus:outline-none focus:ring-2 focus:ring-blue-700`

### Primary Button (Send Greeting / Test Store)

- Height: 40px minimum
- Padding: 8px vertical, 16px horizontal
- Background: blue-700
- Text: white, 14px, weight 500
- Border-radius: 6px
- Active state: opacity-90 (no hover states — mobile-only, source: REQUIREMENTS.md UX-02 principle)

Tailwind: `h-10 px-4 bg-blue-700 text-white text-sm font-medium rounded-md active:opacity-90`

Note: No `hover:` variants. Interaction is touch only (principle applies from Phase 1 to avoid rework).

### IPC + Store inline layout

Name input and Send button sit in a single row with an 8px gap:
```
<div class="flex gap-2">
  <input class="flex-1 ..." />
  <button class="shrink-0 ...">Send</button>
</div>
```

## Interaction States

| Element | States |
|---------|--------|
| Name input | idle, focused (blue ring), filled |
| Send button | idle, active (opacity-90), loading (disabled + text "Sending...") |
| Test Store button | idle, active (opacity-90), loading (disabled + text "Testing...") |
| IPC response area | idle ("— awaiting —"), loading, success (green-600 text), error (red-600 text) |
| Store status area | idle ("— not tested —"), loading, success (green-600 text), error (red-600 text) |
| Version rows | static display only |
