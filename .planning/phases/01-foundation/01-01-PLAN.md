  <name>Task 1: Verify and configure Android SDK, NDK, and JDK</name>
  <what-built>Nothing yet -- this is environment setup that requires human action. Claude cannot install Android Studio or configure macOS system environment variables.</what-built>
  <how-to-verify>
    The user must complete the following steps, then confirm:

    1. Install Android Studio if not already installed (https://developer.android.com/studio)
    2. Open Android Studio > Settings > SDK Manager
    3. Install: Android SDK Platform 34, Android SDK Build-Tools (latest), NDK (Side by side) version 28+
    4. Add these exports to ~/.zshrc (or ~/.zprofile):
       ```
       export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
       export ANDROID_HOME="$HOME/Library/Android/sdk"
       export NDK_HOME="$ANDROID_HOME/ndk/$(ls $ANDROID_HOME/ndk/ | sort -V | tail -1)"
       export PATH="$PATH:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin"
       ```
    5. Source the profile: `source ~/.zshrc`
    6. Verify all three:
       ```
       echo $JAVA_HOME   # Should print a path ending in /jbr/Contents/Home
       echo $ANDROID_HOME # Should print ~/Library/Android/sdk
       echo $NDK_HOME     # Should print ~/Library/Android/sdk/ndk/<version>
       java -version      # Should show JDK 17+
       adb --version      # Should show Android Debug Bridge version
       ```
    7. (Optional) Connect an Android device via USB and enable USB debugging, or create an Android emulator in Android Studio
  </how-to-verify>
  <resume-signal>Type "env ready" when all three environment variables are configured and verified, or describe any issues encountered.</resume-signal>
</task>

    B) Update .gitignore (per D-10, SCAF-05):
    Append the following block to the END of the root `.gitignore` file:

    ```

    gen/
    ```

    The `gen/` pattern at root level will match `apps/tauri-todo/src-tauri/gen/` because git applies .gitignore patterns recursively. This prevents thousands of auto-generated Gradle/Android project files from being tracked.
