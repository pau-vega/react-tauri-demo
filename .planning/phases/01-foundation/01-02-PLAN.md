| JS (WebView) -> Rust (IPC) | Frontend invoke() calls cross into Rust backend via Tauri IPC bridge |
| Rust -> Android filesystem | Store plugin writes to app data directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02 | Tampering | greet command input | accept | `format!("Hello, {}!", name)` in Rust is safe against injection -- Rust's format! does not interpret the string as code. This is a demo command. |
| T-01-03 | Elevation of Privilege | tauri.conf.json5 capabilities | mitigate | Only `mobile-capability` is referenced. Capability file (Plan 03) grants only `core:default` and `store:default` per D-35 -- minimal permissions. |
| T-01-04 | Information Disclosure | store.json on disk | accept | Store data is local todo text, not secrets. No encryption needed per RESEARCH Security Domain analysis. |
